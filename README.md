# Smart Irrigation System Using Arduino

An Arduino-based automated irrigation system designed to optimise water usage by monitoring soil moisture levels and controlling the water pump accordingly. The system also monitors air quality and displays real-time sensor information on an LCD.

### ✨ Key Features

- **Soil Moisture Monitoring:** Detects soil moisture levels using a soil moisture sensor.
- **Automated Water Pump Control:** Automatically switches the water pump ON when the soil moisture falls below the configured threshold and switches it OFF when sufficient moisture is detected.
- **Air Quality Monitoring:** Uses an MQ135 gas sensor to monitor air quality.
- **LCD Display:** Displays soil moisture conditions, water pump status, and air quality readings.
- **Sensor-Based Automation:** Uses sensor inputs and predefined threshold values to automate irrigation with minimal manual intervention.

### 🛠️ Hardware Components

- Arduino Uno
- Soil Moisture Sensor
- MQ135 Gas Sensor
- Relay Module
- Water Pump
- 16×2 LCD Display with I2C Interface
- Breadboard and Jumper Wires

### 💻 Tech Stack

- **Programming Language:** C / Arduino C++
- **Development Environment:** Arduino IDE
- **Libraries:** LiquidCrystal_I2C, MQ135
